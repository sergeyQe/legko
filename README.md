# legko-speedtest

Консольный скрипт на Python для замера скорости скачивания. Делает несколько запросов к одному адресу **строго по очереди**, на каждый дожидается полного ответа, затем печатает среднее время запроса, общий объём и скорость.

## Требования

- Python 3.10 или новее
- Зависимости: `requests` (для тестов — `pytest`), список в `requirements.txt`

## Установка

Windows (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```
python main.py <url> [--count N] [--timeout S] [-v | -vv]
```

Пример на публичном файле 10 МБ (замер занимает около 10–30 секунд, зависит от канала):

```
python main.py https://proof.ovh.net/files/10Mb.dat
```

Мгновенная проверка на маленькой картинке из этого репозитория (≈10 КБ, скорость на таком размере неточна, но проверить, что скрипт работает, можно сразу):

```
python main.py https://raw.githubusercontent.com/sergeyQe/legko/main/tests/data/test_image.jpg
```

| Аргумент | Описание | По умолчанию |
|---|---|---|
| `url` | http(s)-адрес, к которому стучаться (например, ссылка на тяжёлую картинку) | обязателен |
| `--count N` | количество запросов | 10 |
| `--timeout S` | таймаут сокета на запрос, секунды | 30 |
| `-v` / `-vv` | логи в stderr: `-v` — INFO, `-vv` — DEBUG | только предупреждения и ошибки |

### Пример вывода

```
Запрос 1/10: 1.86 с, 10 485 760 байт
Запрос 2/10: 1.19 с, 10 485 760 байт
...
Запрос 10/10: 0.73 с, 10 485 760 байт
----------------------------------------
Среднее время запроса : 0.82 с
Общий объём           : 104.86 МБ
Скорость скачивания   : 102.46 Мбит/с
```

Отчёт печатается в stdout, логи — в stderr, поэтому `python main.py <url> > result.txt` сохранит только отчёт.

### Коды возврата

| Код | Значение |
|---|---|
| 0 | успех |
| 1 | ошибка запроса (сеть, таймаут, HTTP-статус не 2xx) — замер прерывается |
| 2 | неверные аргументы |
| 130 | прервано пользователем (Ctrl+C) |

## Единицы и формулы

- **Скорость — Мбит/с** (мегабиты в секунду, 1 Мбит = 10⁶ бит).
- **Объём — МБ**, 1 МБ = 10⁶ байт. В строках по запросам объём в байтах.
- Время — секунды.

```
среднее время = сумма времён всех запросов / количество запросов
общий объём   = сумма размеров всех ответов
скорость      = общий объём в байтах × 8 / сумма времён / 1 000 000
```

Скорость считается как отношение сумм, а не как среднее скоростей отдельных запросов: так запросы с большим временем получают пропорционально больший вес.

## Что важно знать

- **Время запроса** — от отправки запроса до полного чтения тела ответа (не время до первого байта).
- **Одно соединение на все запросы** (`requests.Session`): первый запрос включает DNS, TCP и TLS, поэтому он обычно медленнее остальных.
- **Кеш отключён**: в каждый запрос добавляется заголовок `Cache-Control: no-cache`, чтобы прокси и CDN не завышали скорость. Сервер при этом может его проигнорировать.
- **Сжатие**: объём считается по распакованному телу. Для картинок и архивов сжатия нет, а для текстовых ответов (gzip) скорость будет выше сетевой.
- **Редиректы** выполняются автоматически, их время входит в замер.
- **Таймаут** — это таймаут сокета (на соединение и на ожидание очередной порции данных), а не общий лимит на запрос.
- Некоторые CDN отказывают клиентам с User-Agent по умолчанию (например, `upload.wikimedia.org` отвечает 403/429). В этом случае скрипт завершится с кодом 1 и сообщением об ошибке; используйте другой адрес.

## Тесты

```
python -m pytest
```

Тесты не используют внешнюю сеть: загрузчик и точка входа проверяются на локальном HTTP-сервере, который отдаёт тестовую картинку `tests/data/test_image.jpg`, раннер — на подменном загрузчике.

## Архитектура

Каждый модуль отвечает за одно (SOLID), зависимости направлены на абстракции.

| Файл | Назначение |
|---|---|
| `main.py` | точка входа, сборка объектов, коды возврата |
| `cli.py` | разбор и проверка аргументов |
| `downloader.py` | `Downloader` (абстракция) и `HttpDownloader` — один запрос с замером времени и размера |
| `runner.py` | `SpeedTestRunner` — N последовательных запросов |
| `calculator.py` | `StatsCalculator` — среднее время, объём, скорость |
| `reporter.py` | `Reporter` (абстракция) и `ConsoleReporter` — вывод |
| `models.py` | `RequestResult`, `SpeedReport` |
| `logging_config.py` | настройка логирования |
| `tests/` | тесты |
